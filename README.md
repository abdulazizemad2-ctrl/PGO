# تجميعات وأسئلة الـ MED لـمادة أحكام الإلتزام

اختبار تفاعلي فيه 243 سؤالاً مرتبة حسب فصول ملخص أحكام الإلتزام: أسئلة من تجميعات الاختبارات السابقة، وأسئلة جديدة للمواضيع التي لم تأتِ عليها أسئلة.

الأسئلة من تجميعات الطلاب وقنوات مجتمع الحقوق، وتنسيق ملخصات أبو عماد.

- قناة التليجرام: https://t.me/molaksat_aboemad

الموقع صفحة واحدة (`index.html`) بلا أي اعتماديات، ويمكن نشره عبر GitHub Pages.
